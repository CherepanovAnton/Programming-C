#### 11
`git diff` — команда, которая показывает различия между версиями файлов, коммитами, ветками и состояниями.
* `git diff` сравнивает текущий измененный файл `sort.c` на диске (в Working Directory) с его версией в индексе (`staged`).
* `git diff --staged` показывает различия между проиндексированным файлом `sort.c` (в состоянии `staged`) и последним зафиксированным коммитом (`HEAD`) для этого файла.
