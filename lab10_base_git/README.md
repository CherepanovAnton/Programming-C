# 📁 Лабораторная работа 10: Базовая работа с Git и GitHub

Практическо-исследовательская работа по изучению распределенной системы контроля версий Git и принципов совместной разработки на платформе GitHub.

---

## 🎯 Задачи работы

Учебный план лабораторной работы разделен на уровни сложности в зависимости от целевой оценки:

### 🥉 Уровень «Оценка 3» (Базовый цикл)
* **Часть 1:** Инициализация локального репозитория, индексация изменений (`git add`), фиксация состояний (`git commit`) и отправка веток на удаленный сервер (`git push`). Изучение утилиты просмотра истории изменений (`git log`) с анализом хэш-значений коммитов, метаданных авторов и временных меток.
* **Часть 2:** Работа с удаленными репозиториями, синхронизация локальных и удаленных изменений, базовая навигация по истории проекта.

### 🥈 Уровень «Оценка 4» (Ветвление и инспектирование)
* **Часть 1:** Изучение механизмов сравнения различных состояний кода. Освоение утилиты `git diff` для инспектирования незафиксированных изменений в рабочих файлах (сравнение рабочей директории со стадией `staged`) и флага `--staged` для проверки проиндексированных изменений перед коммитом.
* **Часть 2:** Работа с ветвлением (`git branch`, `git checkout`/`git switch`). Создание изолированных веток для разработки фич и интеграция их в основную ветку разработки.

### 🥇 Уровень «Оценка 5» (Конфликты слияния и интерактивный rebase)
* **Часть 1:** Изучение продвинутых механизмов редактирования истории, выборочное сохранение и отмена строк в индексируемых текстовых файлах.
* **Часть 2:** Моделирование и разрешение **конфликтов слияния (Merge Conflicts)**. Анализ маркеров конфликта (`<<<<<<< HEAD`, `=======`, `>>>>>>>`), ручной разбор идентичных участков кода в конфликтующих функциях и фиксация финального стабильного состояния.

### 🌟 Дополнительное задание «Звезда» (Вложенные репозитории)
* Изучение механизмов связывания независимых проектов.
* Создание отдельного внешнего репозитория `SubModules` (содержащего `README.md` и исходный код вспомогательных функций `functions.c`).
* Интеграция стороннего проекта в основной репозиторий в качестве зависимого подмодуля с помощью утилиты `git submodule add`.
