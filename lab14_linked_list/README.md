# 📁 Лабораторная работа №14: Динамические структуры данных. Связанные списки

Лабораторная работа посвящена ручному управлению памятью в Си, созданию динамических линейных структур данных и оценке вычислительной сложности алгоритмов.

### 🎯 Задача работы (Что нужно было сделать)
* **Реализовать структуру узла списка**: Описать структуру `Node`, содержащую полезные данные и указатель на следующий элемент (для односвязного списка) или два указателя — на следующий и предыдущий (для двусвязного списка).
* **Разработать интерфейс управления списком**: Написать функции динамического выделения памяти (`malloc`) для создания списка, добавления новых элементов в начало/конец, поиска элементов, удаления узлов по индексу и обязательной полной очистки памяти (`free`).
* **Провести оценку сложности**: Проанализировать написанные функции и сопоставить их скорость работы с нотацией Big O.

## 📊 Визуализация структуры данных

Принципиальная схема связывания динамической памяти при реализации односвязного списка, где каждый элемент ссылается на следующий узел в куче (Heap), а финал замыкается на нулевой указатель:

```text
  [ Head ]
     │
     ▼
┌───────────┐      ┌───────────┐      ┌───────────┐
│ data:  10 │      │ data:  20 │      │ data:  30 │
│ next:  ───┼─────>│ next:  ───┼─────>│ next: NULL│
└───────────┘      └───────────┘      └───────────┘
```

## ⏱ Сложность базовых операций (Big O)

| Структура данных | Поиск по значению | Доступ по индексу | Вставка в начало | Удаление по индексу |
| :--- | :--- | :--- | :--- | :--- |
| **Связанный список** | $O(n)$ | $O(n)$ | $O(1)$ | $O(n)$ |
| **Обычный массив** | $O(n)$ | $O(1)$ | $O(n)$ | $O(n)$ |

### Классы сложности алгоритмов
* **$O(1)$** (Константная) — моментальный доступ, время не зависит от объема данных (например, взятие элемента из массива по индексу).
* **$O(n)$** (Линейная) — время растет пропорционально количеству элементов (один проход циклом по всему связанному списку).
