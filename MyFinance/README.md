# МоиФинансы

Автоматизированная обработка банковских выписок с веб-интерфейсом.

## Возможности

- Чтение CSV- и XLSX-выписок из четырёх банков: Альфа-Банк, Сбербанк, Т-Банк, ВТБ
- Автоматическое определение банка по имени файла
- Приведение всех выписок к единому формату (дата, сумма, описание)
- Категоризация доходов и расходов на основе ключевых слов
- Фильтрация переводов между своими счетами
- Круговые диаграммы доходов и расходов с легендой
- Веб-интерфейс на Flask (localhost:5000)
- Модульные тесты (pytest + pytest-check)
