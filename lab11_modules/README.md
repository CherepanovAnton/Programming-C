# 📂 Лабораторная работа №11: Модульное программирование и составные типы данных (struct)

Лабораторная работа посвящена изучению принципов модульного программирования (многофайловых проектов) на языке Си, а также применению пользовательских структур данных.

### 🎯 Задача работы
* **Разделение монолитного кода**: Освоить перенос логики программы из одного файла в независимые функциональные модули.
* **Работа с заголовочными файлами**: Научиться выносить прототипы функций и объявление пользовательских типов (`struct`) в файлы `*.h`, а реализацию алгоритмов — в файлы `*.c`.
* **Сборка многокомпонентных программ**: Научиться компилировать проекты, состоящие из нескольких исходных файлов, с помощью компилятора `gcc`.

---

## 🚀 Инструкция по компиляции и запуску

Сборка программ выполняется вручную через терминал. Так как проекты являются модульными, компилятору необходимо передавать все исходные файлы задач.

### Сборка и запуск Task 3 (однофайловый вариант):
```bash
gcc task_3.c -o task_3
./task_3
```

### Сборка и запуск Task 4 (модульный вариант):
Перейдите в папку и скомпилируйте все файлы проекта (например, `main.c` и зависимые модули `*.c`):
```bash
cd task_4
gcc *.c -o task_4
./task_4
cd ..
```

### Сборка и запуск Task 5 (модульный вариант):
```bash
cd task_5
gcc *.c -o task_5
./task_5
cd ..
```
