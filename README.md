## 🚀 Способы сборки и просмотра лабораторных

Сначала склонируйте репозиторий себе на локальную машину:
```bash
git clone https://github.com/CherepanovAnton/Programming-C.git
cd Programming-C
```

Поскольку каждая лабораторная работа имеет свою уникальную специфику (где-то используется автоматическая сборка через `CMake`, где-то чистая компиляция одного файла через `gcc`, а где-то представлены только скриншоты работы с `GDB` или `Git`), **точные инструкции по запуску и отчеты находятся внутри каждой конкретной папки в локальных файлах `README.md`**.

Чтобы запустить или изучить работу:
1. Перейдите по ссылке на нужную папку в таблице выше.
2. Прочитайте краткую инструкцию, расположенную внутри папки.
