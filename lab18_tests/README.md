# Тестирование ПО: от теории к практике

## Жизненный цикл разработки ПО (SDLC)
1. **Анализ требований** — что разрабатывать?
2. **Планирование** — ресурсы, сроки, кто делает
3. **Дизайн/Архитектура** — HLD и LLD схемы
4. **Разработка** — кодинг, отладка, сборка
5. **Тестирование** — проверка на ошибки и уязвимости
6. **Развертывание и обслуживание** — документация, релиз, поддержка

## Два подхода к тестированию

| Тип | Описание |
|-----|----------|
| **Ручное (Manual)** | Тестировщик взаимодействует с приложением напрямую |
| **Автоматизированное (Automation)** | Написанный код сравнивает ожидание с реальностью |

## Виды тестов

| Вид | Что проверяет | Сложность |
|-----|---------------|-----------|
| **Модульные (Unit)** | Отдельные функции, компоненты | Низкая |
| **Интеграционные (Integration)** | Взаимодействие модулей (например, с БД) | Средняя |
| **Функциональные (Functional)** | Бизнес-требования (результат действия) | Средняя |
| **Сквозные (E2E)** | Поведение пользователя в контексте всего приложения | Высокая |
| **Приемочные (Acceptance)** | Соответствие бизнес-требованиям | Высокая |
| **Производительности (Performance)** | Надежность, скорость, масштабируемость | Высокая |
| **Smoke-тесты** | Основные функции (быстро, после сборки) | Низкая |

> **Важно:** Интеграционный тест = "могу ли я отправить запрос в БД". Функциональный = "возвращает ли БД нужное значение".

## Фазы тестирования
- **Pre-Alpha** — прототип, много ошибок
- **Alpha** — тестирование внутри компании
- **Beta** — тестирование конечными пользователями
- **Release Candidate (RC)** — регрессионное тестирование
- **Release** — финальная версия

## BDD (Behavior-Driven Development)

**Проблема классического подхода:** сначала пишем код, потом пытаемся его протестировать.

**Решение BDD:** сначала описываем поведение программы (тесты), затем пишем код, который этому поведению соответствует.

### Плюсы BDD
- Фокус на маленькой задаче
- Тесты служат документацией
- Код решает только одну проблему

### Минусы
- Разработка замедляется (сначала тесты)
