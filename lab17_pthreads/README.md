# Многопоточное программирование на C (Pthreads)

Процессы vs Потоки

| Характеристика | Процесс | Поток (thread) |
|----------------|---------|----------------|
| Память | Изолирована, не разделяет | Разделяет память процесса |
| Создание | Тяжелое (копирование ресурсов) | Легкое ("легковесный процесс") |
| Коммуникация | Требует IPC (трубы, очереди) | Через общую память напрямую |
| Отказ | Не убивает другие процессы | Может убить весь процесс |

**Состояния процесса в Linux:** R (Running), D (Uninterruptible Sleep), S (Interruptable Sleep), T (Stopped), Z (Zombie)

**Состояния потока:** Выполняется, Готов, Заблокирован, Сон
