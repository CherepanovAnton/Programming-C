# Файловый ввод/вывод в C: от теории к практике

## Основные понятия
- **Файл** — именованная область внешней памяти.
- **Поток (stream)** — логический канал для операций ввода/вывода.
- **Стандартные потоки**: `stdin`, `stdout`, `stderr`.

## Kernel Space vs User Space
- **Kernel Space** — привилегированная область ядра (полный доступ к железу).
- **User Space** — область пользовательских программ (изолирована, безопасна).
- **Системные вызовы (syscall)** — интерфейс между user space и kernel space.

## Почему буферизация?
- Промежуточный буфер в ядре ускоряет работу за счёт:
  - уменьшения прямых обращений к медленному HDD.
  - кэширования данных (чтение "вперёд").
  - оптимизации порядка записи для многих процессов.
- Буферизация в user space (stdio) снижает частоту системных вызовов и переключений контекста.

## Два подхода к I/O

### 1. Системные вызовы (файловый I/O)
`open`, `close`, `read`, `write`, `lseek`, `sync`
- Минимум копирований (только ядро ↔ HDD).
- Хорошо для больших объёмов данных (видео/аудио).

### 2. Буферизированный I/O (стандартная библиотека C)
`fopen`, `fclose`, `fprintf`, `fscanf`, `fgets`, `fputs`, `fread`, `fwrite`, `fseek`, `ftell`, `fflush`
- Дополнительный буфер в user space.
- Меньше системных вызовов → быстрее для частых мелких операций.
- Режимы открытия: `r`, `w`, `a`, `r+`, `w+`, `a+`, с `b` — для бинарных файлов.

## Типы файлов
- **Текстовые** — работа через `fprintf`/`fscanf`, построчное чтение.
- **Бинарные** — работа через `fread`/`fwrite` (побайтово, без преобразований).

## Полезные функции
- `fflush` — сброс буфера stdio в ядро.
- `fseek`/`ftell` — управление позицией в файле.
- Всегда проверяйте `fopen` на `NULL` и обрабатывайте ошибки через `perror`.

## Пример
```c
FILE *f = fopen("file.txt", "r");
if (!f) { perror("fopen"); exit(1); }
char buf[256];
while (fgets(buf, sizeof(buf), f)) {
    printf("%s", buf);
}
fclose(f);
