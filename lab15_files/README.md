# 📁 Лабораторная работа №15: Файловый ввод/вывод в C: от теории к практике

Лабораторная работа посвящена изучению низкоуровневых и буферизованных механизмов взаимодействия с файловой системой, а также работе с различными форматами хранения данных.

### 🎯 Задача работы (Что нужно было сделать)
* **Разработать парсер текстовых таблиц (`score-3`)**: Реализовать чтение структурированных текстовых данных из файла формата `staff.csv` с разбором строк на отдельные поля и загрузкой их в массив структур.
* **Реализовать бинарную базу данных (`score-4`)**: Освоить побайтовую запись и чтение структур без преобразования в текст (`fread`/`fwrite`) с сохранением данных в файл `database.dat`. Реализовать механизм быстрого произвольного доступа и позиционирования внутри бинарного файла.
* **Изучить архитектуру ввода-вывода**: Понять механизмы буферизации данных в User Space и вызова системных функций ядра (Kernel Space) для минимизации переключения контекста процессора.

## 📊 Сравнительный анализ двух подходов к I/O

| Характеристика | Системные вызовы (Низкоуровневый I/O) | Буферизированный I/O (Стандартная библиотека C) |
| :--- | :--- | :--- |
| **Функции** | `open`, `close`, `read`, `write`, `lseek` | `fopen`, `fclose`, `fread`, `fwrite`, `fseek` |
| **Пространство** | Прямое обращение из User Space в Kernel Space | Использование буфера библиотеки `stdio` в User Space |
| **Эффективность** | Лучше для редкого чтения огромных блоков (видео, потоки) | Быстрее для частых мелких операций (циклы, посимвольный парсинг) |
| **Портируемость** | Зависит от ОС (POSIX-стандарт для Linux) | Стандарт ANSI C (будет работать на любой платформе) |

## ⚙️ Специфика обработки форматов данных

### 📄 Текстовые файлы (на примере `staff.csv`)
* Данные хранятся в виде ASCII-символов, строки разделены символом переноса (`\n`), поля — разделителем (запятая/точка с запятой).
* Обработка выполняется построчно через функции `fgets` или форматированно через `fscanf`.
* Требует парсинга строк и явной конвертации текста в числа (функции `atoi`, `atof`).

### 💾 Бинарные файлы (на примере `database.dat`)
* Данные сбрасываются из памяти на диск побайтово в неизменном «сыром» виде (дамп оперативной памяти).
* Запись и чтение происходят блоками фиксированного размера за один системный вызов через `fwrite(&record, sizeof(Record), 1, f)`.
* Скорость работы максимальна (нет этапа парсинга и конвертации строк). Произвольный доступ реализуется мгновенным перемещением указателя на нужный байт через `fseek`.
